# Real-Time AI Group Chat Application

A full-stack, real-time group chat application featuring instant messaging, secure authentication, cloud media sharing, and AI-powered smart replies.

##  Technologies Used

- **Backend:** Node.js, Express.js
- **Database:** MySQL, Sequelize ORM
- **Real-Time Engine:** Socket.IO
- **Security:** JSON Web Tokens (JWT), bcrypt
- **Cloud Storage:** AWS S3 (Amazon Simple Storage Service), Multer
- **Artificial Intelligence:** Google Gemini API (Smart Replies)
- **Frontend:** HTML, CSS, Vanilla JavaScript (Fetch API)

##  Key Features
- **Secure Authentication:** JWT-based login and signup with encrypted passwords.
- **Room-based Chat:** Users can create groups, add members, and chat in isolated Socket.IO rooms.
- **Instant Messaging:** Real-time bi-directional communication with online/offline user status tracking.
- **Cloud Media Sharing:** Direct image uploads to AWS S3 buckets.
- **AI Smart Replies:** Context-aware reply suggestions powered by Google's Gemini 2.5 Flash model.
